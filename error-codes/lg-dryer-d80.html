LG Dryer d80 Error Code

LG says d80, d90 and d95 (Flow Sense) mean airflow is restricted somewhere between the dryer and the outside. The number is roughly how blocked the vent is: 80, 90 or 95 percent. Also shown as d90, d95 on some models.

Step 1

What usually causes d80

Most common first. In my experience the first one or two on this list account for most LG d80 calls.

  1. 1. Lint-clogged exhaust duct inside the wall
  2. 2. Crushed, kinked or coiled vent hose behind the dryer
  3. 3. Exterior vent flap stuck or clogged with lint
  4. 4. Clogged lint filter
  5. 5. Duct run too long or with too many elbows
Step 2

What to try before you call

Safe things a homeowner can do. Unplug the dryer before reaching into anything.

  1. Clean the lint filter and wash it in warm water if it has a film on it.
  2. Pull the dryer out and check the duct for crushing, kinks or coils. Replace foil hose with rigid or semi-rigid duct.
  3. Go outside and confirm the vent flap opens fully while the dryer runs on Air Dry. Clear lint from the hood.
  4. Reduce the load size and run the cycle again.
Step 3

When to stop and call a technician

The code keeps coming back after the visible duct and hood are clean, which usually means the blockage is inside the wall run. At that point the fix is usually a part, and guessing at parts gets expensive fast. I test first, then quote, so you only pay for what is actually broken.

Questions

LG d80 questions

How do I clear the d80 code on my LG dryer?

Fix the cause first, then unplug the dryer (or turn it off at the breaker) for about a minute and restart. The code clears once the dryer no longer sees the problem. If it comes right back, the cause is still there.

Is d80 the same as d90 / d95?

Yes. LG uses different displays on different model years, so the same problem shows up as d80 on some machines and d90 or d95 on others. The fix is the same.

Is a LG dryer with a d80 error worth repairing?
