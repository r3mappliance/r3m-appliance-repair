Whirlpool Washer F5 E2 Error Code

Whirlpool and Maytag say F5 E2 means the door (or the lid on a top-loader) is not locking properly. Also shown as F5E2 on some models.

Step 1

What usually causes F5 E2

Most common first. In my experience the first one or two on this list account for most Whirlpool F5 E2 calls.

  1. 1. Door not fully latched, or clothing caught in the opening
  2. 2. Overloaded drum pressing against the door
  3. 3. Dirty or misaligned latch
  4. 4. Failed door lock assembly
  5. 5. Wiring or control fault
Step 2

What to try before you call

Safe things a homeowner can do. Unplug the washer before reaching into anything.

  1. Open the door, clear any laundry from the opening and close it firmly.
  2. Reduce the load so the clothes tumble freely.
  3. Unplug the washer for 5 minutes to reset, then restart.
  4. Look at the latch hook and strike for debris and wipe them clean.
Step 3

When to stop and call a technician

The door closes properly but the washer still will not lock, or the lock will not release. At that point the fix is usually a part, and guessing at parts gets expensive fast. I test first, then quote, so you only pay for what is actually broken.

Questions

Whirlpool F5 E2 questions

How do I clear the F5 E2 code on my Whirlpool washer?

Fix the cause first, then unplug the washer (or turn it off at the breaker) for about a minute and restart. The code clears once the washer no longer sees the problem. If it comes right back, the cause is still there.

Is F5 E2 the same as F5E2?

Yes. Whirlpool uses different displays on different model years, so the same problem shows up as F5 E2 on some machines and F5E2 on others. The fix is the same.

Is a Whirlpool washer with a F5 E2 error worth repairing?
