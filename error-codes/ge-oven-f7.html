GE Oven / Range F7 Error Code

GE says F7 usually points to the key panel: a stuck or shorted key. F2 means the oven temperature went above its safety threshold. Also shown as F2 on some models.

Step 1

What usually causes F7

Most common first. In my experience the first one or two on this list account for most GE F7 calls.

  1. 1. Stuck or shorted key on the control panel (F7)
  2. 2. Moisture or grease in the keypad ribbon connection (F7)
  3. 3. Faulty oven temperature sensor (F2)
  4. 4. Sticking oven relay on the control board (F2)
  5. 5. Failed electronic oven control board
Step 2

What to try before you call

Safe things a homeowner can do. Unplug the oven / range before reaching into anything.

  1. Turn the range off at the breaker for 1 to 2 minutes, then restore power and see if the code clears.
  2. Wipe the control panel dry and press each key to find one that sticks.
  3. For F2, do not use the oven until it is checked. The cooktop burners are usually still safe to use.
  4. If the code comes back, leave the range off at the breaker until it is serviced.
Step 3

When to stop and call a technician

The code returns after a breaker reset, or right away for F2 if the oven overheats or will not shut off. At that point the fix is usually a part, and guessing at parts gets expensive fast. I test first, then quote, so you only pay for what is actually broken.

Questions

GE F7 questions

How do I clear the F7 code on my GE oven / range?

Fix the cause first, then unplug the oven / range (or turn it off at the breaker) for about a minute and restart. The code clears once the oven / range no longer sees the problem. If it comes right back, the cause is still there.

Is F7 the same as F2?

Yes. GE uses different displays on different model years, so the same problem shows up as F7 on some machines and F2 on others. The fix is the same.

Is a GE oven / range with a F7 error worth repairing?

Usually yes. Key panel / touch pad and similar parts cost a fraction of a new oven / range. I tell you the price before any work starts, and if a repair is not worth it I say so.
