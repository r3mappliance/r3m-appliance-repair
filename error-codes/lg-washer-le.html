LG Washer LE Error Code

LG says LE means the motor is overloaded and locked, so the tub could not spin. It usually comes from an overload or something jammed in the drum. Also shown as LE1 on some models.

Step 1

What usually causes LE

Most common first. In my experience the first one or two on this list account for most LG LE calls.

  1. 1. Overloaded drum
  2. 2. Coins, keys or other objects jammed between tub and drum
  3. 3. Motor overheated
  4. 4. Faulty motor hall sensor
  5. 5. Failed motor or control board
Step 2

What to try before you call

Safe things a homeowner can do. Unplug the washer before reaching into anything.

  1. Unplug the washer for 5 to 30 minutes so the motor can cool, then restart.
  2. Take some laundry out and try a smaller load.
  3. Check the drum for coins, keys or other objects and remove them.
  4. Run a Spin Only cycle with the drum empty to see if the code returns.
Step 3

When to stop and call a technician

The code returns on an empty, cooled-down washer, or the drum will not turn freely by hand. At that point the fix is usually a part, and guessing at parts gets expensive fast. I test first, then quote, so you only pay for what is actually broken.

Questions

LG LE questions

How do I clear the LE code on my LG washer?

Fix the cause first, then unplug the washer (or turn it off at the breaker) for about a minute and restart. The code clears once the washer no longer sees the problem. If it comes right back, the cause is still there.

Is LE the same as LE1?

Yes. LG uses different displays on different model years, so the same problem shows up as LE on some machines and LE1 on others. The fix is the same.

Is a LG washer with a LE error worth repairing?

Usually yes. Motor hall sensor and similar parts cost a fraction of a new washer. I tell you the price before any work starts, and if a repair is not worth it I say so.
