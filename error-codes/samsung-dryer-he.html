Samsung Dryer HE Error Code

Samsung says the HE / hE / HC family of codes means the dryer is getting too hot, and almost always the reason is restricted airflow. Also shown as hE, HC, hC, HC4 on some models.

Step 1

What usually causes HE

Most common first. In my experience the first one or two on this list account for most Samsung HE calls.

  1. 1. Clogged lint screen
  2. 2. Blocked or crushed exhaust duct behind the dryer or in the wall
  3. 3. Low supply voltage on electric dryers
  4. 4. Faulty thermistor or high-limit thermostat
  5. 5. Failed heating element or control board
Step 2

What to try before you call

Safe things a homeowner can do. Unplug the dryer before reaching into anything.

  1. Clean the lint screen. If it feels coated, wash it with warm water to remove fabric softener film.
  2. Disconnect the vent duct behind the dryer and clean it out along with the exterior vent hood.
  3. Make sure the duct is not kinked or crushed when the dryer is pushed back.
  4. Unplug the dryer for a minute, restart and run a timed dry to see if the code returns.
Step 3

When to stop and call a technician

The code returns after the lint screen and the full vent path are clean. At that point the fix is usually a part, and guessing at parts gets expensive fast. I test first, then quote, so you only pay for what is actually broken.

Questions

Samsung HE questions

How do I clear the HE code on my Samsung dryer?

Fix the cause first, then unplug the dryer (or turn it off at the breaker) for about a minute and restart. The code clears once the dryer no longer sees the problem. If it comes right back, the cause is still there.

Is HE the same as hE / HC / hC / HC4?

Yes. Samsung uses different displays on different model years, so the same problem shows up as HE on some machines and hE or HC or hC or HC4 on others. The fix is the same.

Is a Samsung dryer with a HE error worth repairing?
