LG Washer UE Error Code

LG says capital UE means the washer stopped because the load is unbalanced and needs you to fix it. Lowercase uE means the washer is still trying to rebalance on its own by adding water and moving the clothes around. Also shown as uE on some models.

Step 1

What usually causes UE

Most common first. In my experience the first one or two on this list account for most LG UE calls.

  1. 1. Laundry piled on one side of the drum, or a single bulky item
  2. 2. Load too large or too small
  3. 3. Washer not level
  4. 4. Worn suspension or shock absorbers
  5. 5. Items that hold water unevenly: pillows, bath mats, waterproof jackets
Step 2

What to try before you call

Safe things a homeowner can do. Unplug the washer before reaching into anything.

  1. If you see uE, wait. If it turns into UE, open the door and spread the load evenly.
  2. Fill the drum to about two-thirds and add a few items when washing one bulky piece.
  3. Put a level on the washer and adjust the feet so it does not rock.
  4. Avoid washing waterproof items or a single heavy rug alone.
Step 3

When to stop and call a technician

A level washer with a balanced load still stops with UE on every spin. At that point the fix is usually a part, and guessing at parts gets expensive fast. I test first, then quote, so you only pay for what is actually broken.

Questions

LG UE questions

How do I clear the UE code on my LG washer?

Fix the cause first, then unplug the washer (or turn it off at the breaker) for about a minute and restart. The code clears once the washer no longer sees the problem. If it comes right back, the cause is still there.

Is UE the same as uE?

Yes. LG uses different displays on different model years, so the same problem shows up as UE on some machines and uE on others. The fix is the same.

Is a LG washer with a UE error worth repairing?

Usually yes. Shock absorbers or suspension rods and similar parts cost a fraction of a new washer. I tell you the price before any work starts, and if a repair is not worth it I say so.
